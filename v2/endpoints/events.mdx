<Warning>
  **Planned, not yet available.** Events are listed in the v2 release plan for Phase 1, but no `/v2/.../events` paths exist in the current dev OpenAPI spec — so these endpoints have no API playground yet. The paths below are from the release plan and may change. Until v2 events ship, use the [v1 events endpoints](/reference/businesses/events/fetch_businesses_events).
</Warning>

All event endpoints are **synchronous**.

## Business events

| Purpose | Endpoint |
| :--- | :--- |
| Events | `/v2/businesses/events` |
| Enrollments — Add | `/v2/businesses/events/enrollments` |
| Enrollments — Update | `/v2/businesses/events/enrollments` |
| Enrollments — Delete | `/v2/businesses/events/enrollments` |
| Enrollments — Get | `/v2/businesses/events/enrollments` |

## Prospect events

| Purpose | Endpoint |
| :--- | :--- |
| Events | `/v2/prospects/events` |
| Enrollments — Add | `/v2/prospects/events/enrollments` |
| Enrollments — Update | `/v2/prospects/events/enrollments` |
| Enrollments — Delete | `/v2/prospects/events/enrollments` |
| Enrollments — Get | `/v2/prospects/events/enrollments` |

<Note>
  The four enrollment operations share one path. The HTTP methods that distinguish them are not yet specified in the v2 plan and will be documented before GA.
</Note>

## Renamed fields

The `new_funding_round` event payload on `POST /v2/businesses/events` corrects two misspelled field names:

| Current (typo) | Correct in v2 |
| :--- | :--- |
| `founding_stage` | `funding_stage` |
| `founding_date` | `funding_date` |

<Warning>
  **Breaking change.** Any consumer reading `founding_stage` or `founding_date` from a `new_funding_round` payload must be updated. See [What's new](/v2/whats-new#signal-fixes).
</Warning>
