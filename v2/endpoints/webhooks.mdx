<Warning>
  **Planned, not yet available.** Webhooks are listed in the v2 release plan for Phase 1, but no `/v2/webhooks` paths exist in the current dev OpenAPI spec — so these endpoints have no API playground yet. The paths below are from the release plan and may change. Until v2 webhooks ship, use the [v1 webhooks endpoints](/reference/webhooks/webhooks).
</Warning>

All webhook endpoints are **synchronous**.

| Purpose | Endpoint |
| :--- | :--- |
| Add | `/v2/webhooks` |
| Get | `/v2/webhooks/{partner_id}` |
| Delete | `/v2/webhooks/{partner_id}` |
| Check connectivity | `/v2/webhooks/check_connectivity` |

<Note>
  Webhook behavior itself — payload shape, retries, and delivery guarantees — is unchanged in scope by the v2 plan. Only the path prefix moves to `/v2`.
</Note>
