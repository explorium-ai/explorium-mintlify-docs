## Single endpoint

Autocomplete is consolidated to one endpoint:

```
POST /v2/autocomplete
```

There are no longer separate autocomplete endpoints under `prospects` and `businesses`.

<Warning>
  **Breaking change.** Any v1 code calling a business- or prospect-specific autocomplete path must move to `/v2/autocomplete`.
</Warning>
